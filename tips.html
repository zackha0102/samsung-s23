S23 팁


공통 (전 모델 가능)

  • 손날로 밀어서 스크린샷
  • 측면 버튼 두 번 눌러서 앱 실행
  • 배터리 85% 충전 제한 설정
  • 화면 주사율 120Hz 고정
  • Good Lock으로 UI 커스텀
  • 삼성 인터넷 꿀기능
  • 야간 모드 자동 켜기

S23+ 가능

  • 45W 고속충전 활용
  • 더 큰 배터리로 절전 모드 없이 하루 종일 사용

S23 Ultra만 가능

  • S펜으로 화면 꺼진 상태에서 메모 (Always On Memo)
  • S펜 에어 액션 (허공에서 제스처로 앱 조작)
  • 10배 광학줌 촬영
  • 삼성 덱스 + S펜 동시 활용
  • S펜으로 번역, 확대, 텍스트 선택
